# Monitoreo de temperatura y humedad con ESP32
Registro de temperatura y humedad relativa usando un termohigrómetro conectado a un ESP32.

## Propósito
Documentar y organizar el análisis de datos de un sensor termohigrómetro (datos ficticios, uso docente).

## Pregunta de trabajo
¿Cómo varían la temperatura y la humedad relativa a lo largo del día?

## Variables de interés
- fecha_hora: marca de tiempo de la medición
- temperatura: temperatura del aire (°C)
- humedad_relativa: humedad relativa del aire (%)

## Metadatos
- Fuente: datos ficticios generados para la clase
- Licencia: por definir
- Método de medición: sensor termohigrómetro  con ESP32 (modelo DHT22)
